## Choix défendable

Critères prioritaires dans l'ordre : pas de seconde soumission incertaine ; secrets hors modèle/rapport ; preuve métier explicite ; reprise et budget auditables ; portabilité ; facilité de navigation ; coût. Choix : moteur propriétaire de politique et journal, navigateur Playwright remplaçable, fournisseur JSON sans outils et sans fallback. Éviter de réécrire le navigateur et de déléguer le verdict métier au modèle.

La baseline Playwright écrite obtient les mêmes verdicts sur les huit scénarios comparés, avec moins de temps et de capture/journal. Notre apport mesuré est le maintien des garde-fous dans le moteur et la reprise après interruption ; aucune supériorité de découverte autonome n'a été mesurée. Playwright reste préférable pour une régression connue et stable. Stagehand/Browser Use méritent un futur essai sur la navigation sémantique ; mabl apporte une plateforme plus complète aujourd'hui ; Meticulous cible mieux la régression visuelle issue de sessions.

Génération : Playwright planner/generator est une voie intéressante pour rédiger une campagne, mais les scénarios générés doivent passer une revue de consentement et d'oracles. Les réparations/replays automatiques sont incompatibles avec nos intentions déjà tentées. Les captures actuelles ne sont pas un moteur de jugement esthétique ; baselines visuelles approuvées ou revue indépendante restent nécessaires.
